# Post Management System

A simple Post Management System built using React and Vite. It allows users to create, view, edit, delete, search, and filter posts.

## Features
- Create new posts with title, author, content, and tags
- View complete post details
- Edit and delete posts
- Search posts by title
- Filter posts by author
- Pagination with 5 posts per page
- Form validation with error messages
- Store posts in browser localStorage
- Responsive user interface

## Technologies Used
- React.js
- Vite
- React Router DOM
- HTML, CSS, JavaScript
- Browser localStorage

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/deychotu2-cloud/popst-management.git
   ```

2. Open the project folder:
   ```bash
   cd popst-management
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open the local URL shown in the terminal.

## Data Storage
Posts are stored in the browser's localStorage. Data remains in the same browser unless it is cleared.
